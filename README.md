# Крест vs Земельный кодекс

Небольшая браузерная игра-дуэль на HTML5 Canvas без сборки — просто откройте `index.html`.

## Запуск

```
python3 -m http.server 8000
```

и откройте `http://localhost:8000`. (Открыть `index.html` напрямую двойным кликом тоже работает, но некоторые браузеры блокируют загрузку локальных картинок без сервера.)

## Персонажи

- **Отец Аркадий** — персонаж в кепке, кидается крестами.
- **Землемер** — персонаж без кепки, кидается земельными кодексами.

## Управление

| Кто | Движение | Атака |
|---|---|---|
| Отец Аркадий (кепка) | `A` / `D` | `Пробел` — бросить крест |
| Землемер (без кепки) | `←` / `→` | `Enter` — бросить земельный кодекс |

У каждого 100 очков здоровья, попадание снаряда снимает 8 очков. Побеждает тот, кто первым обнулит здоровье соперника.

## Финальные заставки

- Если побеждает **Отец Аркадий** — показывается православный храм, и звучит фраза: *«Царствие Божие наступило благодаря стараниям Святого отца Аркадия»*.
- Если побеждает **Землемер** — показывается заставка про Земельный кодекс, и звучит фраза о том, что восторжествовали неизменные законы земли и никто не сможет нарушить закон об аренде земли на 49 лет.

## Как подставить свои картинки

Игра уже полностью рабочая — без картинок персонажи и снаряды рисуются кодом (плейсхолдеры). Чтобы использовать ваши изображения, просто положите файлы с точными именами в папку `assets/` — игра автоматически подхватит их вместо плейсхолдеров, ничего в коде менять не нужно:

| Файл | Что это | Рекомендуемый размер |
|---|---|---|
| `assets/character-cap.png` | Отец Аркадий (в кепке) | ~300×450, прозрачный фон |
| `assets/character-nocap.png` | Землемер (без кепки) | ~300×450, прозрачный фон |
| `assets/cross.png` | снаряд-крест | ~64×64, прозрачный фон |
| `assets/land-code.png` | снаряд-земельный кодекс | ~64×64, прозрачный фон |
| `assets/church.png` | фон финальной заставки при победе Отца Аркадия | 900×480 |

Заставка при победе Землемера рисуется кодом и не требует картинки (при желании её тоже можно заменить — скажите, и добавлю такой же механизм).
